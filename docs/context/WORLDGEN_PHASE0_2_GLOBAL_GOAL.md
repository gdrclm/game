## T — terrain and bathymetry audit and completion
Read Phase 1 field/algorithm/record contracts and actual pipeline; build a feature matrix: physical feature / causal inputs / fields / extraction / records / downstream consumer / tests / actual maps / status (implemented, partial, absent, intentionally deferred). Audit current elevation and marine masks; do not assume pre-marine height is final truth. Verify one consistent final land/water/elevation representation relative to sea level, including offshore uplift and cleanup/carving. Preserve original fields and provenance; add versioned compatible outputs only as warranted. Normalize units and thresholds explicitly; no invented metres from normalized height.
- Tectonics: uplift/subsidence/fractures, convergent/divergent/transform boundaries, ridge direction, arcs, hotspots, volcanic zones. Verify geological support, not random labels.
- Land relief: mountains/ridges, hills, plateaus, plains, lowlands, basins/depressions, valleys/gorges/canyons, passes, slopes, coastal belts. At macro grid scale represent coherent regional features and local refinement hints where resolution cannot support a literal narrow canyon. Distinguish morphology with elevation, slope, local relief, curvature/drainage/tectonics; no labels unsupported by geometry. Check actual land mask and connected records.
- Bathymetry: submerged shelves, shallow water, continental slope, deep basins, underwater ridges/depressions, volcanic seamounts, coastal gradients, bays and straits, at supported scale. Audit whether the current fields represent these consistently; implement minimal causal coverage of missing physical capabilities, not merely new names. Check sea depth sign and coastal consistency, and underwater continuity; do not assign arbitrary depths after carving.
- Hydrology: watersheds, drainage direction, rivers, lakes, estuaries, lowland wetness; flows follow final terrain or explicitly justified exceptions; diagnose closed basins, disconnected catchments, uphill flows, source/sink problems, coastline transitions.
- Climate: latitude/temperature/moisture, wind and relief interaction, rain shadows, coastal influence, storms and seasonality. Verify links and controls, not necessarily detailed physical climate simulation. Phase 2 interprets existing truth; long-term local post-collapse erosion/evolution belongs to 18–19.
- Spatial implications: distinct accessibility, shelter, freshwater availability, resource/habitat potential, navigable channels and constraints; no fabricated settlements, history, mineral deposits or exact gameplay costs. Geological substrate/resource carriers only if existing contracts require them; otherwise record deferred scope. Preserve measured passage closures and independent route analysis.
For each feature verify actual examples, negative controls and coverage across diverse seeds. Not every feature must occur in every world. Produce reasoned notes for features inappropriate at 256x128 resolution and explicit handoff to later phases, instead of adding noise or pretending completion.
