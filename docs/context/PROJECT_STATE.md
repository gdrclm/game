При перекрытии гибридный граф пересчитывает реальные водные пути и полную цену поездки. Медиана общих водных шагов снизилась с 58,6% до 33,1%. Некоторые миры сохраняют общие узкие магистрали. [Сеть, физика и карты](review/f8q/README.md#проливы-и-маршруты)
