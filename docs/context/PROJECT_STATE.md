- В исходных тестах 77 из 78 перекрытий захватывали порт. Теперь 113 обходов и два разрыва подтверждены с фиксированными доступными портами на основной выборке. При перекрытии гибридный граф пересчитывает реальные водные пути и полную цену поездки. Медиана общих водных шагов снизилась с 58,6% до 33,1%. Некоторые миры сохраняют общие узкие магистрали. [Сеть, физика и карты](review/f8q/README.md#проливы-и-маршруты)

Маршруты Phase 2 читают фактические связи с морем, рельефом и проливами. [Распределения по узлам и по мирам](review/f8q/comparison.json)
