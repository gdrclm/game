## Причина и реализация

В 04-B быстрому темпу по-прежнему передавалась структурная надёжность бассейна. Верхняя оценка подпитки при повторном стрессе умножала обычную структурную поддержку на сезонную долю. При одинаковых структурной поддержке и доле маловодья две области с разным абсолютным притоком получали одну верхнюю оценку. На прежнем входе `4144686569` мировой темп был 0,371215 при реакции на повторный стресс 0,360779. На `2248663653` он был 0,142924 при реакции 0,163596, хотя две крупнейшие области получали около 0,034–0,036 единицы обычной подпитки на клетку.

Phase 2 теперь фиксирует масштаб при приёме канонической географии. Опорная плотность `r` — максимальная измеренная обычная подпитка на макроклетку среди непустых областей рельефа этого мира. Для обычной плотности `q` вклад равен `q / (q + r)`, для маловодной плотности `l` — `l / (q + r)`. При одинаковой обычной и опорной плотности обычный вклад равен половине, при нулевой подпитке оба вклада нулевые. Числители и знаменатель имеют одинаковые единицы. Общий знаменатель сохраняет непосредственно измеренную долю маловодья `l / q` между двумя вкладами. Локальное изменение объёма при фиксированной опоре меняет оба вклада даже при той же сезонной доле. Равномерное масштабирование всей географии, включая опорную плотность, сохраняет относительные индексы. Это внутримировой показатель возможности восстановления.

Экологическая часть быстрого темпа использует обычную плотность. Коэффициент реакции на повторный стресс ограничен меньшей из двух величин, измеренной маловодной поддержкой и бассейновой оценкой доступного стока с учётом риска. Сезонная доля остаётся видимой в диагностике. Её повторное применение уже к маловодной величине дублировало бы дефицит. Площадь бассейна по-прежнему влияет на давление, дефицит и верхнюю границу при повторном стрессе.

Быстрый темп разделяет экологическую работу и возобновление движения. Прямой маршрутный сигнал и существующая надбавка за маршрутное окно сохраняют свои веса и могут действовать при нулевой подпитке. Пригодность местности ограничивает работу по всей области, включая часть, обеспеченную движением по отдельному маршруту. Параметры абсолютной подпитки проверяются на входе Phase 2. Исторические входы без нового опорного поля сохраняют прежний расчёт.

Устойчивость убежищ и интервал стабилизации на фиксированных входах сохраняют значения. Экологическая подпитка, геометрия доставки, бюджет источника и потенциальное удержание остаются отдельными данными. Для фактического времени удержания нужны измерения потерь. Смысл новых индексов ограничен возможностью восстановления в фазах 0–2.

## Малые выборки и контрфактуалы

Нормировка без выделения движения исправляла пять целевых отказов и теряла проходившие `42` и `16908799`. Отделение только прямого маршрутного сигнала от водной поддержки сохраняло их канонические входы. Низкая волатильность приводила к оценке 0,179374 и отказу `relief_relevance`. При снятии ограничения местности со всего маршрутного вклада проходили погодные пары, а обязательный `359393571` останавливался по `tension_vs_relief` при восстановлении 0,304749.

При отделении обоих маршрутных вкладов в сочетании с отдельной нормировкой маловодья независимый `2869486218` терял экспорт при оценке 0,289670. Знаменатель для маловодья уменьшался вместе с притоком и сглаживал спад. Общий знаменатель сохраняет измеренное отношение. Он возвращает `2869486218` при оценке 0,286789 и сохраняет контроль низкой волатильности при 0,180228. Вес каждого маршрутного вклада сохранён.

На фиксированном `42/relief_001` опорная плотность равна 0,131975 и сезонная доля 0,545416. Уменьшение обоих притоков вдвое при той же доле изменяет быстрый темп с 0,182776 до 0,161479 и реакцию на повторный стресс с 0,183610 до 0,158621. Изменения пути, подъёма, доступного бюджета источников и потенциального хранения проверяются раздельно.

Перенос маловодной подпитки из укрытия при фиксированной сумме меняет только устойчивость этой области с 0,314193 до 0,142167.
